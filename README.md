### 🚀 Главный проект

🔥 **[Watch-N-Learn Demo](https://github.com/akireev80/watch-n-learn-demo)** — *Модуль интерактивного видеоплеера и синхронизации субтитров (фрагмент кода)*
> Изолированная фронтенд-часть образовательной платформы **Tivali**. Проект перенесен на актуальный стек **Next.js 16 (App Router)** и **React 19**.

* **Двунаправленная синхронизация:** Сквозная связь между HTML5 Video API и таблицей субтитров (клик для перемотки и умный автоскролл).
* **Раздельное аудио-управление:** Независимое динамическое изменение громкости и темпа речи для каждого спикера в реальном времени.
* **Высокая производительность:** Стабильность интерфейса без скачков (Layout Shifts) через `ResizeObserver` и GPU-визуализация частот (Web Audio API) на 60 FPS.
* **Глубокий i18n:** Полная адаптация под RTL-локали с инверсией сеток через CSS Grid и изоляцией текста тегами `<bdi>`.

👉 **[Посмотреть Live Demo](https://akireev80.github.io/watch-n-learn-demo/ru/apps/watch-n-learn/videos/1.html)**
